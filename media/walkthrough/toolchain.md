# Select a C/C++ toolchain

CPM builds with the toolchain you select: **GCC**, **MinGW-w64**, **MSYS2** or **LLVM/Clang**.

- **Select toolchain** lists the installations CPM detected and lets you add another root or `bin` folder.
- **Install toolchains** proposes the supported packages when nothing is installed yet.

Home shows the result as pills — `gcc`, `g++`, `ar`, `gdb` — that turn red when an executable is missing.
