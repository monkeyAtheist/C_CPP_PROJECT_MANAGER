# Open or create a workspace

A CPM **workspace** (`.cws`) groups one or more **projects** (`.prj`), in the spirit of LabWindows/CVI.

- **Open** an existing `.cws` or `.prj`. CPM also opens a workspace automatically when the folder you open in VS Code contains one.
- **Create** a starter workspace: C or C++, executable, DLL or static library, with build settings ready to use.

Recently opened workspaces are listed on the Home page.
