# Build with Ctrl+F7

The status bar shows the active configuration, for example `PowerSupplyCtl · D64 · EXE`. Click it to switch between **D32 / R32 / D64 / R64** and **EXE / DLL / LIB**.

- **Ctrl+F7** builds the active project and its dependencies in build order.
- Errors and warnings go to the **Problems** view; their count appears in the status bar and on Home.
- **Settings & Tools** holds every project option: compiler, linker, build steps, CMake backend, packages.
